# football-matches-bot

Daily UEFA digest at 10:00 Europe/Berlin. Two messages: yesterday results, then today's fixtures. DeepSeek web search, then structured Telegram.

Competitions: UCL, Europa, Conference, Nations League, Euro/World Cup UEFA qualifiers. Ukraine/Serbia first, then other.

`/matches` — regen now.

`.env`: `TELEGRAM_TOKEN`, `DEEPSEEK_API_KEY`, `CHAT_ID`
